# AI Config Workflow Skill

This skill describes how to maintain `.ai` content for sync operations.

Guidance:
- Add `.md` files under `.ai/rules/` for policy, project goals, and sync behavior.
- Add `.md` files under `.ai/skills/` for assistant behavior, troubleshooting, and shell conventions.
- Use clear filenames that reflect intent, such as `project-overview.md` or `shell-cli-maintenance.md`.
- Keep messages short, explicit, and tool-agnostic.
- Do not rely on generated tool outputs being editable; update `.ai` sources instead.
